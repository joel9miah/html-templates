## Template Customization Guide

### Getting Started

1. Open the selected HTML template.
2. Review its page structure.
3. Customize the page title.
4. Update text and content.
5. Adjust CSS styles.
6. Test the page in a browser.

### Best Practices

- Use semantic HTML elements.
- Add descriptive page titles.
- Maintain readable code.
- Check mobile responsiveness.
- Validate HTML structure.

### Browser Testing

Test templates in modern web browsers
before publishing them.
## Manual Testing Checklist

- [ ] Open an available HTML template in a browser.
- [ ] Check page headings, images and link destinations.
- [ ] Review the layout on desktop and mobile widths.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
